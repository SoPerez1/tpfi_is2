# Installation

## Stable release

To install TPFI_IS2, run this command in your terminal:

```sh
uv add TPFI_IS2
```

Or if you prefer to use `pip`:

```sh
pip install TPFI_IS2
```

## From source

The source files for TPFI_IS2 can be downloaded from the [Github repo](https://github.com/SoPerez1/TPFI_IS2).

You can either clone the public repository:

```sh
git clone https://github.com/SoPerez1/TPFI_IS2
```

Or download the [tarball](https://github.com/SoPerez1/TPFI_IS2/tarball/main):

```sh
curl -OJL https://github.com/SoPerez1/TPFI_IS2/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd TPFI_IS2
uv sync
```
